 Kumpulan Resep Masakan App

 Deskripsi Project

Kumpulan Resep Masakan App merupakan aplikasi web berbasis CodeIgniter 4 yang digunakan untuk menampilkan kumpulan data resep makanan secara realtime menggunakan Public API TheMealDB.

Aplikasi ini dibuat untuk memenuhi tugas Ujian Tengah Semester mata kuliah Pemrograman Web/API.



 Fitur Utama

- Menampilkan Daftar Resep Makanan
- Detail Resep Makanan
- Gambar Makanan Realtime
- Informasi Kategori Makanan
- Informasi Asal Negara Makanan
- Bahan-Bahan Masakan
- Langkah-Langkah Memasak
- Dashboard Responsive
- UI Modern dengan Bootstrap 5
- Error Handling menggunakan Try-Catch
- Menggunakan Public API TheMealDB



Teknologi Yang Digunakan

- CodeIgniter 4
- Bootstrap 5
- PHP
- TheMealDB API
- HTML
- CSS
- JavaScript



 Struktur MVC

 Controller
Mengatur alur aplikasi dan mengambil data dari Public API menggunakan HTTP Client bawaan CodeIgniter 4.

 View
Menampilkan data resep makanan dalam bentuk card Bootstrap dan halaman detail resep.

 Routing
Mengatur perpindahan halaman antara halaman utama dan halaman detail resep.


 API Yang Digunakan

List Resep Makanan
https://www.themealdb.com/api/json/v1/1/search.php?s=

Detail Resep Makanan
https://www.themealdb.com/api/json/v1/1/lookup.php?i=
